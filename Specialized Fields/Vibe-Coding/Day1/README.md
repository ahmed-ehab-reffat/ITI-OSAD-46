# Sorting Algorithms & Data Structures Visualizer

This small project demonstrates sorting algorithms (bubble, selection, insertion, merge, quick) and simple data structure visualizers (stack, queue, linked list).

- Code is modular (ES modules) under `src/`.
- Styles are in `styles/style.css`.

To run: open `index.html` in a modern browser that supports ES modules.

Files:
- `index.html` - main page
- `styles/style.css` - styling
- `src/main.js` - app entry
- `src/ui.js` - UI and glue code
- `src/visualizer.js` - drawing helpers
- `src/algorithms/sort.js` - sorting algorithms
- `src/datastructures/*.js` - simple DS visualizers
